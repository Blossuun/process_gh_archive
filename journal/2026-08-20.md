# 2026-08-20 일지

## 문제

### 증상

    wget https://data.gharchive.org/2026-08-01-15.json.gz

데이터 생김새와 크기를 확인하기 위해 위 명령어를 PowerShell에서 사용했는데, 데이터가 보이지 않음.

### 원인

PowerShell에서 `wget`은 `Invoke-WebRequest`의 별칭으로, `-OutFile`을 안 주면 응답을 파일로 저장하지 않고, 결과를 화면에 출력만 함.

### 해결

    wget https://data.gharchive.org/2026-08-01-15.json.gz -OutFile 2026-08-01-15.json.gz

위와 같이 명시적으로 저장.

## 의사결정

### 재현가능성

재현 가능한 프로젝트를 만들기 위해, uv로 패키지 관리를 수행하고 duckdb와 같은 데이터베이스 사용을 스크립트로, 결과를 산출물로 생성하도록 구성.

### 질문 수정

기존 질문 1의 내용이 "Git workflow를 조사해 통계에 기반한 best practice 작성하기" 였는데, 이제 보니 GHArchive는 local에서 일어나는 Git 작업에 대한 기록을 확인할 수는 없고, Github api에 의해 일어나는 작업들에 대해서만 기록이 남는 것을 알게됨.

따라서 질문 1의 내용을 "Github Keyword 조사"로 수정하고, 새로운 질문으로 "AI 사용이 활발한 시간대 추측"을 추가함.

이 과정에서, Claude Opus와 나눈 대화 요약

    키워드 조사에서는, Git commit 과정에서 사용되는 관습적인 키워드는 제외해야 함.
    또한 Spike 키워드를 조사한다고 목표를 명확히 함.
    
    AI 사용 시간대 추측에 대해서
        - Push 이벤트는 봇에 의해 발생되는 양이 많음
        - 중국에서 발생하는 이벤트와 AI 사용량과의 관계
        - 이벤트에는 지역 정보가 적혀있지 않음
        - 이벤트에 적힌 AI 서명
    이러한 내용들에 대한 논의를 바탕으로, 도전적인 과제인 점을 인식하고 진행해야 함을 상기시킴.
