## 분석 진행 중 방향 수정

처음 실행해 얻은 `table_inventory.json`을 다시 읽다가 BigQuery에 데이터를 2016년 6월 23일부터 적재를 시작했는지 이전의 데이터들은 테이블에 생성한 날짜가 상당히 어긋나있음을 확인함.

원래 프로젝트의 목표에 사용할 범위가 5년 이내이기도 했고 오래된 데이터일수록 변수가 크다고 생각해 지금 하는 분석에서 2016년 7월 이전의 데이터를 제외하기로 결정.

추가로, 초기 분석은 메타데이터를 일 단위로 불러와 수행했지만 누락 날짜가 존재한다는 것을 확인했기 때문에, 실제 다운로드 가능한 데이터의 단위인 시간 단위의 데이터가 완전한지 확인하는게 필요하다고 판단되어 이 작업을 수행함.

시간 단위로 데이터의 완전성을 조사하는 작업을 모든 날짜에 대해서 조사하기엔 BigQuery 샌드박스의 quota가 부족하기 때문에, 바이트 수의 spike가 있는 날짜와 데이터가 존재하지 않는 날짜들의 인접 날짜를 대상으로 조사 범위를 제한.
