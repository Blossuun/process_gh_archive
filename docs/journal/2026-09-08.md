### 측정 진행하며 참고할만 한 정보

파일을 단순하게 파일명으로 sorting 한 이후 처리하게 되면, 처리되는 순서가

    1시 -> 10시 -> 11시 -> ... -> 2시 -> 20시 -> 21시 -> ... -> 3시 -> ... -> 9시

이런 식으로 흘러감.  
이는 나중에 파이프라인 설계 시 처리 순서에 영향을 끼칠 수 있으므로 유의해야 한다고 판단.
