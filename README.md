# Process GH Archive
GH Archive 데이터를 제한된 하드웨어 리소스로 처리해보는 프로젝트.

## 목표

### Github Keyword 조사

Github API에서 발견되는 키워드의 통계를 내서, 가장 많이 보이는 키워드를 조사하고, 해당 키워드가 많이 보이는 이유를 뉴스나 이슈 등을 동반해 분석하기.

### AI 사용이 활발한 시간대 추측

GH Archive에 나오는 정보로는 AI를 사용해 생성한 이벤트인지, 사람이 직접 수행한 이벤트인지 구분할 수 없다.

하지만 2026년에 개발을 하고 있으면, AI를 사용하고 있는 시간이라고 생각한다. 따라서 개발 중이라고 여겨지는 시간대를 알아낼 수 있으면, AI 사용률이 높을 것이라 예상되는 시간대를 추정할 수 있을 것이라 생각한다.

- 제약과 가정
    - Bot이 발생시킨 Event를 제외해야함.
    - 중국의 Event: 중국은 자국의 AI를 활용할 확률이 높고, 이는 원하는 정보가 아니라 제외할 수 있으면 제외해야 함. 다만 지역에 대한 정보는 GH Archive에 없으므로, 방법을 고민해야함.
    - 개발자만이 AI를 사용하는 것은 아니지만, AI 리소스 사용률에서 높은 비율을 차지하고 있다고 가정.
    - AI 서명이 적힌 Event의 시간대를 조사해서, 개발중인 시간이라고 추정할 수 있는 시간대와 비교해서 곡선의 모습이 유사하면, 실제 AI 사용률이 높은 시간대라고 추정할 수 있음.

### AI 모델이 아닌 일주일간 스타 증가율 상위 OSS 리포 조사하기

Trending repository를 검색하면, AI 모델 repository가 많이 나오는데, 이는 내가 trending repository를 검색했을 때 알고 싶은 정보가 아니였다.

Trending repository 안에서도, OSS만을 선별해 뜨는 repository 목록을 만들어볼 예정이다.

### 언어, 라이브러리 유행 조사

시간이 지나면서 언어, 라이브러리의 유행이 바뀌는데, 카테고리별로, 영역별로 추이를 조사해보는 것도 의미가 있을 것이다.
